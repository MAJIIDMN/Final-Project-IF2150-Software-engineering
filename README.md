# Nama Aplikasi
Aplikasi desktop berbasis Python dengan arsitektur MVC dan PyQt5.

## Prasyarat
- Python 3.10+
- pip

## Instalasi
pip install -r requirements.txt

## Menjalankan Aplikasi
python src/main.py

## Pembagian Modul
- models: berisi struktur backend (data dan logic)
- views: tampilan GUI
- controllers: jembatan antara view dan model
